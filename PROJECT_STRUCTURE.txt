================================================================================
  ARCHITECTURE FLOW — HOW AUDIO PLAYBACK WORKS
================================================================================

  User clicks track
       │
       ▼
  PlayerContext.playTrack()          ─── TS: sets state, calls Tauri commands
       │
       ├─► invoke("stop_playback")   ─── commands.rs: drops old PlaybackHandle
       │
       └─► invoke("play_track")      ─── commands.rs: play_track()
            │
            ▼
         player::start()             ─── player.rs:
            ├─ decoder::open_audio()       Opens file via Symphonia
            ├─ probe_exclusive()           Tests WASAPI exclusive (Windows only)
            ├─ setup_shared_output()       Falls back to cpal shared if needed
            ├─ SampleQueue::new()          Creates thread-safe sample buffer
            ├─ Pipeline::new()             Resampler + EQ + preamp state
            ├─ Backend::Cpal/Wasapi        Opens audio output device
            └─ spawn "vynlore-decode"      Decoder thread:
                 │
                 ▼
              run_decoder()           ─── Loop: refill -> pump -> flush_tail
                 │                         Gapless chaining via try_chain()
                 ▼
              Pipeline::pump()        ─── Apply preamp -> EQ -> push to queue
                 │
                 ▼
              SampleQueue             ─── Thread-safe bridge (decoder <-> output)
                 │
                 ▼
              cpal callback /         ─── Pop from queue -> apply volume/balance
              WASAPI render loop           -> write to audio device
                                           -> push to SpectrumAnalyzer
                                              -> emitted as "spectrum-data" event
                                                 -> WaveformSeekbar / SpectrumBars
